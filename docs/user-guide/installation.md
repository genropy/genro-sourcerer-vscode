# Installation

## From VS Code Marketplace

1. Open VSCode
2. Go to Extensions (Ctrl+Shift+X)
3. Search for "Sourcerer Visual"
4. Click **Install**

Or from the command line:

```bash
code --install-extension genropy.genro-sourcerer-vscode
```

## From VSIX

Download the `.vsix` file from the [GitHub Releases](https://github.com/genropy/genro-sourcerer-vscode/releases) page, then:

```bash
code --install-extension genro-sourcerer-vscode-0.1.0.vsix
```

## Requirements

- VSCode 1.85.0 or later
- A running Sourcerer instance with API access
- An authentication token (get one from your Sourcerer admin)
